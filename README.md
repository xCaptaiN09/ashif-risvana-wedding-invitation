# 💍 Ashif & Risvana Jasmin — Wedding Invitation

An interactive, 3D cinematic wedding invitation web experience celebrating the wedding reception of **Ashif & Risvana Jasmin**.

Built with a scroll-driven hardware video scrub engine, grand editorial luxury typography, responsive layout, and ambient music.

---

## 🌟 Highlights & Features

- **📜 Sacred Invocation:** Traditional Arabic calligraphy Bismillah (`بِسْمِ اللَّهِ الرَّحْمَنِ الرَّحِيمِ`) styled with Google Fonts `Amiri`.
- **🎞️ 3D Cinematic Envelope Scrub:** Custom 1080p intra-keyframe video scrubbing driven by scroll progress with authentic wax seal cracking and flap physics.
- **👑 Grand Formal Invitation Card:** High-contrast cotton paper card with deckle borders, symmetrical family lineage, structured date & timing grid, and Royal Palace venue details.
- **📍 Interactive Location & Map:** Google Maps integration for directions to **Royal Palace, Perumpadappu, Malappuram**.
- **🎵 Ambient Audio:** Subtle, romantic background music triggered on initial user interaction.
- **📱 Fluid Responsiveness:** Optimized for all screen sizes from mobile to ultra-wide displays.

## 🛠️ Technology Stack

- **Vite** — Fast modern frontend tooling
- **Vanilla JavaScript (ES6+)** — High performance scroll scrubber with `requestAnimationFrame` and `easeOutCubic` easing
- **Vanilla CSS** — Custom HSL/luxury design system, responsive typography, 3D CSS transforms
- **FFmpeg** — Video intra-keyframe optimization (`-g 1`) for 0ms seek latency
